LilaMD 0.6.0

Tabs, zoom, and readable tables.

**Tabs in one window.** Every file you open (Finder, Cmd+O, Open Recent, drag and drop) opens as a tab in the same window. A file that is already open comes to the front instead of opening twice. Switch with Ctrl+Tab or Cmd+Shift+] / [. Right-click a tab for Close, Close Others, Close Tabs to the Right, Reveal in Finder and Copy Path.

**Autosave, as in Notes.** A file is written 2 s after your last edit and when you switch apps. Closing a tab or the window, or quitting, writes the file and does not ask. Only a new Untitled tab with text asks where to save it. Cmd+S still saves at once.

**Zoom.** Cmd+= / Cmd+- / Cmd+0, or View → Zoom: 80, 90, 100, 110, 120 and 150%. The zoom is the same in every tab and is kept after a restart.

**Tables wrap.** Long text in a table cell now wraps inside the cell in Visual mode, instead of scrolling sideways. Very wide tables still scroll.

**Changed shortcuts.** Cmd+= and Cmd+- now zoom. To add or delete a table row, or to raise or lower a heading level, use Option+Cmd+= / Option+Cmd+-. Cmd+Shift+= / Cmd+Shift+- still add and delete a table column.

**Known limitations**
- Wide cells wrap at about 360 pt at 100% zoom.
- Tabs are not restored after a restart and cannot be moved to their own window.
- Every tab keeps its editor in memory, so undo survives tab switches. 10 tabs of a 6000-line file take about 1.6 GB.
- No Versions, Rename or Move To from the title bar. Use Finder (tab menu → Reveal in Finder).

Install or update: `curl -fsSL https://raw.githubusercontent.com/drkhwo/lilamd/main/install.sh | bash`
