# LilaMD 0.6–0.7: критерии приёмки

Источник: `docs/plans/0.6-0.7-PLAN.md`. Три релиза: R1 таблицы, R2 масштаб, R3 табы.

Обозначения:
- **M** = must (релиз не выходит без этого). **S** = should (можно перенести, но записать причину).
- Проверка: **XCT** = XCTest, **MEAS** = измеренное значение, **MAN** = ручная проверка, **SMOKE** = `scripts/smoke.sh`.
- Окно для замеров: 1100×800 pt.
- Релиз принят, когда все M-критерии прошли, а регрессии REG-* прошли на каждом релизе.

Общие правила проверки:
- Тесты запускать по одному. XCTest открывает настоящие окна.
- Не запускать `scripts/smoke.sh` и `scripts/set-default.sh` на машине Стаса без согласования: они трогают установленное приложение.
- Доказательство каждого MAN-пункта: скриншот или лог в `~/dev/QA/2026-11-04-lilamd-0.6-0.7/<release>/`.
