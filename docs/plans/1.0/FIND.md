# LilaMD 1.0: поиск по документу (⌘F)

## Context
В документе нет поиска. ⌘F в редакторе ничего не делает; на стартовом экране ⌘F ищет по истории (`StartScreenView.swift:191`) — это остаётся.

Решение Стаса (17.11): нужен поиск по ⌘F по открытому `.md`. Поведение — стандарт macOS (Safari, Notes). Замена — не в этом объёме.

## Как выглядит

```
┌─ plan.md ─────────────────────────────────────────────┐
│ plan.md │ notes.md │                                  │  ← вкладки
├───────────────────────────────────────────────────────┤
│ 🔍 [ release          ]  3 of 12   ‹  ›        Done   │  ← строка поиска
├───────────────────────────────────────────────────────┤
│ … the next ▓release▓ goes to the App Store …          │  ← текущее совпадение ярче
│ … every ░release░ note …                              │  ← остальные подсвечены
```

## Поведение
- ⌘F открывает строку поиска над документом активной вкладки и ставит курсор в поле. Если в документе выделен текст, он попадает в поле.
- Повторный ⌘F при открытой строке выделяет текст в поле.
- Поиск на лету, без учёта регистра, по видимому тексту документа (Visual) или по исходнику (Source).
- Все совпадения подсвечиваются, текущее — ярче; документ прокручивается к текущему.
- Счётчик «3 of 12»; нет совпадений — «Not found», поле не краснеет агрессивно.
- Enter или ⌘G — следующее; ⇧Enter или ⇧⌘G — предыдущее; по кругу.
- Esc или Done закрывают строку, подсветка исчезает, курсор возвращается в документ на текущее совпадение.
- ⌘E — «Use Selection for Find» (стандарт macOS).
- Меню Edit ▸ Find: Find… (⌘F), Find Next (⌘G), Find Previous (⇧⌘G), Use Selection for Find (⌘E).
- Строка поиска своя у каждой вкладки: переключение вкладок сохраняет текст поиска и позицию.
- Поиск не меняет файл и не делает вкладку «изменённой»; подсветка не попадает в Markdown и в undo.
- Правка документа при открытом поиске пересчитывает совпадения.

## Вне объёма
- Замена (⌥⌘F), регулярные выражения, «только слово целиком», учёт регистра.
- Поиск по всем вкладкам.

## Проверка
- XCTest (фон): подсветка и счётчик на образце; следующее/предыдущее по кругу; Esc убирает подсветку; файл байт-в-байт не меняется, вкладка не грязная, undo не содержит подсветки; Visual и Source; переключение вкладок сохраняет поиск; правка пересчитывает счётчик.
- С экраном: ⌘F/⌘G/⇧⌘G/⌘E/Esc с настоящей клавиатуры; скриншоты светлой и тёмной темы.
