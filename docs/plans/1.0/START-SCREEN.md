# LilaMD 1.0: стартовый экран и история

## Context
Сейчас запуск без файла сразу открывает системное окно Open (`AppDelegate.openDocument`). Закрытие последней вкладки прячет окно (`MainWindowController.swift:153`), и приложение остаётся без окон. История — только системный File ▸ Open Recent.

Решения Стаса (13.11):
- Стартовый экран — внутри главного окна, не отдельное окно.
- Показывается при запуске без файла и после закрытия последней вкладки.
- В списке: имя + папка + когда, поиск, удаление из списка, закреплённые файлы, восстановление последней сессии.

## Как выглядит

```
┌─ LilaMD ────────────────────────────────────────────┐
│ (полоса вкладок пустая)                             │
├─────────────────────────────────────────────────────┤
│                     🟣 LilaMD                        │
│        [ New ⌘N ]  [ Open… ⌘O ]                     │
│        [ ↺ Restore last session · 3 tabs ]          │
│                                                     │
│   🔍 Search recent files                    ⌘F      │
│                                                     │
│   PINNED                                            │
│   📌 plan.md          ~/dev/QA/…           Today    │
│                                                     │
│   RECENT                                            │
│   ▸  README.md        ~/dev/md-editor      Yesterday│
│      notes.md         ~/Documents          Mon      │
│      old.md           ~/Downloads   not found       │  ← серым
│                                                     │
│          Drop a .md file here to open it            │
└─────────────────────────────────────────────────────┘
```

- Цвета — палитра редактора: фон = страница (`EditorPalette.pageBackground`), строка под курсором и выбранная — как активная вкладка.
- Ширина контента ~560 pt по центру, список прокручивается.
- Пустая история: только кнопки и подсказка про перетаскивание.

## Поведение

**Кнопки**
- New (⌘N) — новая вкладка Untitled.
- Open… (⌘O) — системное окно Open.
- Restore last session — открывает вкладки, которые были открыты при последнем выходе, в том же порядке, активной — ту же. Кнопка видна, только если в прошлой сессии были файлы и хотя бы один из них существует. Текст: «Restore last session · N tabs». Пропавшие файлы пропускаются, в конце — одна строка «2 files not found».

**Список**
- Две секции: Pinned (сверху, в порядке закрепления) и Recent (по дате последнего открытия, новые сверху). Файл в Pinned не повторяется в Recent.
- Строка: имя файла, папка (сокращённая через `~`, середина обрезается), дата («Today 14:05», «Yesterday», день недели, затем «3 Nov»).
- Пропавший файл: строка серая, справа «not found». Клик — вопрос «Remove from the list?».
- Лимит истории: 50 файлов (закреплённые не считаются).

**Поиск**
- Поле сверху списка. ⌘F или просто начать печатать — фокус в поле.
- Фильтр по имени и пути, без учёта регистра, совпадения подсвечиваются.
- Esc очищает поле.

**Клавиатура и мышь**
- ↑/↓ — выбор строки, Enter — открыть, ⌘⌫ — убрать из списка.
- Двойной клик или клик по строке — открыть.
- Правый клик: Open, Show in Finder, Pin / Unpin, Remove from Recent.
- Перетаскивание `.md` на экран — открыть вкладкой.

**Окно**
- Закрытие последней вкладки → стартовый экран, окно остаётся.
- Красная кнопка окна закрывает окно. Клик по иконке в Dock открывает его снова со стартовым экраном.
- File ▸ Open Recent показывает тот же список (Pinned + Recent), Clear Menu очищает Recent, Pinned не трогает.

## Данные

- Своё хранилище истории: `HistoryStore`, запись = закладка на файл (`bookmarkData`), путь для показа, дата последнего открытия, `pinned`.
- Под песочницей App Store закладки — security-scoped (`com.apple.security.files.bookmarks.app-scope`, уже в плане этапа 2). Без них файлы из своей истории не откроются.
- Сессия: при выходе сохраняются закладки открытых вкладок, их порядок и активная. Untitled-вкладки в сессию не попадают.
- Хранение: файл JSON в Application Support приложения (под песочницей — в контейнере). Миграция: при первом запуске история заполняется из системного `NSDocumentController.recentDocumentURLs`.
- Debug-сборки и тесты не пишут в историю установленного приложения (как `-MDEditorRecordsRecents NO` сейчас).

## Проверка (критерии)

- Запуск без файла → стартовый экран, системное окно Open не появляется.
- Запуск с файлом (Finder, `open`) → вкладка, стартовый экран не мелькает.
- Закрыть последнюю вкладку → стартовый экран в том же окне.
- Restore last session открывает те же вкладки в том же порядке с той же активной.
- Pin / Unpin / Remove / поиск / пропавший файл — по XCTest на модели и на представлении.
- История переживает перезапуск; лимит 50 соблюдается.
- Фоновые тесты (`scripts/test.sh`) и прогон с экраном зелёные; скриншоты экрана в светлой и тёмной теме — Стасу.

## Вне объёма
- Предпросмотр содержимого файла в списке.
- Папки и «проекты».
- Синхронизация истории между маками.
