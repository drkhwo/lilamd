# LilaMD 1.0, этап 1: пакет шагов с экраном

Эти шаги забирают экран, клавиатуру, фокус или источник ввода. Разработчики их **не запускают**. Оркестратор запускает пакет целиком, когда Стас отошёл от Mac.

`E` = `/Users/stanislav/dev/QA/2026-11-11-lilamd-1.0`.

## Перед запуском

1. Стас не работает за Mac. Экран разблокирован.
2. Нет другого прогона тестов (`pgrep -fl xcodebuild` пуст).
3. Запомнить текущий источник ввода: шаги, которые его меняют, возвращают его сами, но итог сверяется в конце.

## Правила для шагов

- Один шаг = один скрипт `scripts/fg/<NN>-<имя>.sh`. Запуск из корня worktree.
- Скрипт идемпотентен: повторный запуск даёт тот же результат и чистит за собой прошлые файлы шага.
- Скрипт в конце возвращает исходное состояние: источник ввода, список включённых источников, закрытое Debug-приложение, временные файлы. Возврат — в `trap … EXIT`, чтобы сработал и при ошибке.
- Скрипт работает только с Debug-сборкой из `build/dd`. `/Applications/LilaMD.app` не трогать. `--args -MDEditorRecordsRecents NO`, если шаг не проверяет Open Recent.
- Скрипт пишет доказательства в `E/<task-id>/fg/` и печатает итог одной строкой: `RESULT <шаг> PASS|FAIL <детали>`. Код выхода 0 = PASS.
- Формат описания шага ниже: команда, ожидаемый результат, доказательство, ID критериев.

## Шаг 1. Полный прогон тестов на экране

- Команда: `scripts/fg/01-full-suite.sh`
- Что делает: `scripts/test.sh --foreground`, лог в `E/fg/test.log`.
- Ожидаемо: `** TEST SUCCEEDED **`, `Executed N tests, with K tests skipped and 0 failures`, N ≥ 146. K — только тесты «только для фона» (CLOSE-1), список в REPORT.
- Доказательство: `E/fg/test.log`.
- Критерии: REG-1, REG-3, REG-4, MER-5.
